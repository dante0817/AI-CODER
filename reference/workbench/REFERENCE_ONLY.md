# Reference prototype only

This directory contains the original Workbench & Architecture Control prototype for UI and architecture reference.

**Do not treat this directory as the production execution backend.** It contains deliberate simulations/mock data, including prototype capability probes, conformance results, persistence demonstrations, patch hashing, and task/worktree success flows. AI-CODER v0.5 does not use those simulations as execution evidence.

Production behavior lives in the AI-CODER Desktop/Code-OSS implementations and is migrated only after real tests and parity checks exist.
